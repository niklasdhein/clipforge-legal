Datenschutzerklärung

Stand: 11. November 2026

Was clipforge tut

clipforge ist ein privates Werkzeug, das ausschließlich vom Betreiber genutzt wird. Es lädt freigegebene Videos über die YouTube Data API auf den eigenen YouTube-Kanal des Betreibers hoch.

Welche Daten von Google verarbeitet werden

  • Bei der einmaligen Anmeldung erteilt der Betreiber clipforge die Berechtigung youtube.upload. Google liefert dafür ein Zugangstoken (Refresh-Token).
  • Dieses Token wird nur auf dem eigenen Server des Betreibers gespeichert, in einer Datei, die nur für das Programm lesbar ist. Es wird ausschließlich verwendet, um Videos auf den Kanal des Betreibers hochzuladen.
  • clipforge liest keine weiteren Daten aus dem Google- oder YouTube-Konto, etwa Kontaktdaten, Videos anderer Nutzer oder Statistiken.

Weitergabe

Es werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung genutzt. Diese Seiten verwenden keine Cookies und kein Tracking.

Widerruf und Löschung

Die Berechtigung lässt sich jederzeit unter myaccount.google.com/permissions widerrufen. Das gespeicherte Token wird dann wertlos und vom Betreiber gelöscht.

YouTube und Google

clipforge nutzt die YouTube API Services. Es gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google. Die Nutzung von Daten aus Google-APIs entspricht der Google API Services User Data Policy.

Privacy Policy

Last updated: November 11, 2026

What clipforge does

clipforge is a private tool used solely by its operator. It uploads approved videos to the operator's own YouTube channel via the YouTube Data API.

Google user data

  • During a one-time sign-in the operator grants clipforge the youtube.upload scope. Google returns a refresh token for this.
  • The token is stored only on the operator's own server, in a file readable only by the program, and is used exclusively to upload videos to the operator's channel.
  • clipforge does not read any other data from the Google or YouTube account, such as contacts, other users' videos or analytics.

Sharing

No data is shared with third parties, sold, or used for advertising. These pages use no cookies and no tracking.

Revocation and deletion

Access can be revoked at any time at myaccount.google.com/permissions. The stored token then becomes invalid and is deleted by the operator.

YouTube and Google

clipforge uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service; see also the Google Privacy Policy. clipforge's use of information received from Google APIs adheres to the Google API Services User Data Policy.
